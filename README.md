## 🗺️ 知识体系

整套笔记以**面向对象**为核心，层层递进：

- **基础概念**：数据类型 → 面向对象 → 封装/继承/多态
- **核心关键字**：`private` / `this` / `super` / `static` / `final` / `instanceof`
- **进阶特性**：构造方法 → 方法重写 → 枚举 → 单例 → 抽象类 → 接口
- **内部类体系**：成员/静态/局部/匿名内部类 → Lambda → 方法引用
- **集合框架**：ArrayList / LinkedList / Set 三兄弟 / Map / 迭代器 / 泛型
- **异常与文件**：异常体系 → Stream 流 → File → 递归 → 字符集
- **IO 流**：字节流 / 字符流 / 缓冲流 / 转换流 / 打印流 / 特殊数据流
- **并发编程**：线程 → 线程同步 → 线程池 → 进程与线程
- **网络编程**：IP / UDP / TCP / BS 架构 → 线程池优化
- **框架底层**：反射 → 注解 → 代理 → 单元测试
- **后端开发**：SpringBoot → Redis → MySQL 索引 → JDBC / MyBatis

## 🎯 一点学习心得

整套笔记贯穿几条朴素的原则（详见 [首页.md](./Java_Learn_Obsidian/首页.md)）：

1. 设计从下往上画，编写从上往下写
2. 就近原则优先，可用 `this` / `super` 打破
3. 静态优先于对象存在
4. 统一标准，避免"屎山代码"
5. `String` 不可变，大量拼接用 `StringBuilder`
