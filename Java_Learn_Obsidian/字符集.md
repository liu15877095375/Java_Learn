# 字符集

计算机存字符的方式：先人为规定，把字符跟特定数字建立连接，然后把特定数字转成二进制存入计算机。

---

## 📌 ASCII（美国）

美国用的字符集，字符比较少，一个字符对应一个字节就够了，且开头都是 0。

![](images/2026-08-11-21-25-05-image.png)

---

## 📌 GBK（中国）

一个中文字符编码成两个字节的形式存储。

![](images/2026-08-11-21-30-55-image.png)

---

## 📌 UTF-8（世界通用）

Unicode 字符集的编码方案，可变长编码（1~4个字节），兼容 ASCII。

![](images/2026-08-11-21-36-45-image.png)
