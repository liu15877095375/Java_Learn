# final关键字

最终、不可改变的修饰符，可修饰变量、方法、类。

---

## 🎯 修饰变量
final修饰的变量，是**常量**，在创建时要直接赋值，之后不允许赋值。被final修饰的变量一般用**大写字母**。

### 引用类型的特殊性
如果final修饰的是[[数据类型|引用数据类型]]，比如说 `final Student stu = new Student();`
- 不可改变的是 `stu` 里记录的**内存地址**
- 但是 `stu` 里的属性值，是**可以发生改变**的

> 简单来说：final修饰哪个变量，该变量所记录的内容就无法改变。

---

## 🎯 修饰方法
[[继承|方法重写]]中，private私有方法、static静态方法、final最终方法**不能被重写**。

---

## 🎯 修饰类
final修饰的类为**最终类**，不能被[[继承]]，里面的方法也不能被重写。

---

## 📌 与接口的关系
[[接口]]中的成员变量默认修饰符是 `public static final`（常量）。
