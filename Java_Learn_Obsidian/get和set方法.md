# get和set方法

[[封装|封装数据]]的标准方法，用于访问[[private关键字|私有化]]的成员变量。

---

## 🎯 作用
- 成员变量用[[private关键字]]私有化后，不能通过对象直接使用
- 需要通过public的get/set方法来间接访问和修改变量
- get方法用于获取值，set方法用于设置值

---

## 📌 与this关键字配合
常出现在get和set方法里，用[[this关键字]]区分成员变量和参数局部变量，解决[[#就近原则]]问题。

```java
public void setAge(int age) {
    this.age = age;  // this.age是成员变量，age是参数
}
public int getAge() {
    return this.age;
}
```

---

## ⚡ 快捷键
使用 `alt + insert` 快捷键可以快速创建get/set方法，也可以快速创建[[构造方法]]。

---

## 📌 继承特点
get和set方法是可以[[继承]]父类的，父类有的，子类可以不用写了。

---
