# API

Application Programming Interface，JDK提供的各种功能的Java类。

---

## 🎯 概念
在Java中，API就是JDK提供的各种功能的Java类，是类，要通过new对象来使用。JDK提供了很多API，需要使用时查文档即可。

---

## 📌 导包规则
1. 使用**本包**中的类：不需要导包
2. 使用 `java.lang` 包下的类：不需要导包（核心包，比如[[String类]]就在java.lang下）
3. 使用其他包的类：**需要导包**

---

- [[String类]] - 字符串类（java.lang）
