# 可变参数

Java 5 引入的语法特性，允许一个方法接收 0 个、1 个或多个同类型的实参，本质是对数组的语法糖封装。

---

## 📌 语法格式

```java
修饰符 返回值类型 方法名(参数类型... 参数名) {
    // 方法内部按数组方式使用该参数
}
```

示例：任意数量整数求和

```java
public static int sum(int... numbers) {
    int total = 0;
    for (int num : numbers) {
        total += num;
    }
    return total;
}

// 调用方式非常灵活
sum();              // 传0个参数，numbers是长度为0的空数组
sum(10);            // 传1个参数
sum(1, 2, 3, 4);    // 传多个参数
sum(new int[]{1,2,3}); // 直接传数组也完全兼容
```

---

## 💡 核心本质

编译器在编译阶段，会把可变参数自动转换成**对应类型的数组**。`int... numbers` 和 `int[] numbers` 在字节码层面几乎没有区别。

---

## 📋 硬性规则

- 一个方法**只能有一个**可变参数
- 可变参数必须放在方法参数列表的**最后一位**
  - 错误：`public void test(String... strs, int num)`
  - 正确：`public void test(int num, String... strs)`
- 方法重载时，优先匹配固定参数的方法，匹配不到才走可变参数方法

---

## ⚠️ 常见误区

调用时不传任何参数，可变参数是**长度为 0 的空数组**，不是 `null`，直接遍历不会触发空指针异常。
