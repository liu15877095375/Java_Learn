# ArrayList

[[集合框架]]中最常用的实现类，基于动态数组实现。

---

## 🎯 特点
- 长度可变，自动扩容
- 有序集合（元素存取顺序一致）
- 允许存储重复元素
- 支持索引访问（类似数组）

---

## 📌 使用方式

### 不使用泛型（不推荐）
```java
ArrayList arrayList = new ArrayList();
```
可以接受任意类型，但只能用[[Object类]]接收，存在[[多态#弊端|多态弊端]]。

### 使用泛型（推荐）
用[[泛型]]`<>`限定存储的数据类型：
```java
ArrayList<String> list = new ArrayList<>(); // 只能存String
```
- JDK7+ 后面的泛型类型可以省略（菱形语法），但尖括号要保留
- 泛型只能是引用数据类型，基本数据类型需要用[[包装类]]

## 📊 ArrayList vs LinkedList

| 特性 | ArrayList | [[LinkedList]] |
|------|-----------|----------------|
| **底层实现** | 数组 | 双链表 |
| **查询速度** | 快（索引直接定位） | 慢（从头开始查） |
| **增删效率** | 低（元素需前移/后移） | 高（只需改指针） |
| **内存占用** | 较少 | 较多（需存地址） |
| **首尾操作** | 一般 | 极快（双指针） |

> ArrayList 底层是数组，优缺点与数组类似。
> LinkedList 底层是双链表，优缺点与链表类似，还可用来模拟队列或栈。
