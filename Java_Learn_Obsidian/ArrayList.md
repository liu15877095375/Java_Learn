# ArrayList

[[集合框架]]中最常用的实现类，基于动态数组实现。

---

## 🎯 特点
- 长度可变，自动扩容
- 有序集合（元素存取顺序一致）
- 允许存储重复元素
- 支持索引访问（类似数组）

---

## 📌 使用方式

### 不使用泛型（不推荐）
```java
ArrayList arrayList = new ArrayList();
```
可以接受任意类型，但只能用[[Object类]]接收，存在[[多态#弊端|多态弊端]]。

### 使用泛型（推荐）
用[[泛型]]`<>`限定存储的数据类型：
```java
ArrayList<String> list = new ArrayList<>(); // 只能存String
```
- JDK7+ 后面的泛型类型可以省略（菱形语法），但尖括号要保留
- 泛型只能是引用数据类型，基本数据类型需要用包装类
