# private关键字

[[面向对象基础]]中的核心访问控制关键字，实现[[封装]]的关键手段。

---

## 🎯 核心作用
- 成员变量要用private去私有化
- 工具类要用private去修饰[[构造方法]]，不允许外部创建该类的对象
- [[成员内部类]]可以被private修饰
- [[抽象类与抽象方法|抽象类]]的构造方法不是private的
- [[接口]]没有构造方法，不存在private构造

---

## 📌 使用场景
1. **成员变量私有化** - 配合get/set方法使用
2. **工具类构造方法** - 禁止创建对象，配合[[static关键字]]
3. **成员内部类隐藏** - 在外部类中提供获取方法
