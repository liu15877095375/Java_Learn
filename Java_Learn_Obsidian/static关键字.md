# static关键字

[[面向对象基础]]中的类级别修饰符，修饰共享的变量和方法。

---

## 🎯 核心特性
static关键字修饰的是**共享的变量**，只需要赋值一次就可以了。
一个类下的所有对象，static变量都是一样的，如果有一个对象修改了static变量，那么别的对象的static变量也会跟着变。

---

## 📌 使用规则

### 变量访问
使用static变量，一般直接通过**类名**来使用，如 `Student.teacher`，也可以用对象直接使用，但这是不推荐的。

> 静态变量不属于对象，属于类，随着类的加载而加载，**优先于对象而存在**。

### 工具类设计
工具类要用[[private关键字]]去修饰[[构造方法]]，不允许外部创建该类的对象，然后，其工具方法要用static去修饰，以供外部直接用类名调用。

### 方法调用限制
1. **静态方法**：只能调用静态变量或者静态方法，不能直接调用非静态的变量或者方法
2. **非静态方法**：可以访问静态的变量或者方法，也可以访问非静态的变量或者方法
3. **静态方法里没有this关键字**（见[[this关键字]]）
4. [[main方法]]本身也是一个静态方法，上面三个原则同样适用

---

## 🔗 不能被重写
[[继承|方法重写]]中，private、static、final修饰的方法是不能被重写的（见[[final关键字]]）。
