# Java 学习笔记 🧠

> 本知识库基于面向对象编程核心思想构建，知识点之间通过双向链接互相关联，形成神经网络式的知识图谱。

---

## 📚 核心知识体系

### 🔷 基础概念
- [[数据类型]] - 基本数据类型 vs 引用数据类型
- [[面向对象基础]] - 封装、成员变量
- [[get和set方法]] - 成员变量访问、封装的具体实现
- [[main方法]] - 程序入口、静态方法

### 🔷 核心关键字
- [[private关键字]] - 数据私有化、访问控制
- [[this关键字]] - 就近原则、当前对象引用、内存地址
- [[super关键字]] - 父类引用、调用父类构造/方法
- [[static关键字]] - 静态变量、静态方法、工具类设计
- [[final关键字]] - 常量、最终类、最终方法、不可变性
- [[instanceof关键字]] - 类型判断，为安全强转保驾护航

### 🔷 面向对象三大特性
1. [[封装]] - 数据安全、私有化、get/set
2. [[继承]] - 代码复用、单继承、多层继承、方法重写
3. [[多态]] - 多种形态、编译看左运行看右、类型转换

### 🔷 进阶特性
- [[构造方法]] - 对象初始化、有参无参构造
- [[方法重写]] - Override、虚方法表替换地址
- [[虚方法表]] - 继承与重写的底层实现
- [[枚举类]] - 限制对象个数、枚举项、全局常量、天然单例
- [[代码块]] - 静态代码块、实例代码块、执行顺序
- [[单例设计模式]] - 饿汉式、懒汉式、确保唯一对象
- [[抽象类与抽象方法]] - abstract关键字、抽象方法重写
- [[接口]] - interface、多实现、默认方法、静态方法、私有方法
- [[类型转换]] - 多态弊端的解决、向上/向下转型

### 🔷 内部类体系
- [[内部类总览]]
  - [[成员内部类]] - private修饰、静态内部类
  - [[静态内部类]] - static修饰的成员内部类
  - [[局部内部类]] - 方法内定义
  - [[匿名内部类]] - 接口快速实现、Lambda前身
  - [[Lambda表达式]] - 函数式编程、替代匿名内部类
  - [[方法引用]] - Lambda进一步简化、::操作符

### 🔷 常用API
- [[API]] - JDK提供的类库、导包规则
- [[String类]] - 不可变字符串、串池、常用方法
- [[StringBuilder]] - 可变字符串容器、高效拼接
- [[File类]] - 文件/文件夹操作、遍历、绝对/相对路径

### 🔷 集合框架
- [[集合框架]] - 长度可变容器、遍历方式、并发修改异常
- [[ArrayList]] - 基于数组的List实现，查询快增删慢
- [[LinkedList]] - 基于双链表的List实现，增删快，可模拟队列/栈
- [[Set集合]] - 无序、无索引、元素唯一
  - [[HashSet]] - 基于哈希表，自定义对象需重写hashCode/equals
  - [[LinkedHashSet]] - 哈希表+双链表，有序
  - [[TreeSet]] - 基于红黑树，可排序，需实现Comparable或Comparator
- [[Map集合]] - 双列集合，键值对，HashMap/LinkedHashMap/TreeMap
- [[迭代器]] - 遍历Collection集合，并发修改异常的正确处理
- [[泛型]] - 类型安全限定、ETKV命名、通配符、泛型擦除
- [[包装类]] - 基本类型→对象、自动装箱/拆箱、类型转换

### 🔷 异常处理
- [[异常]] - 异常体系、try-catch捕获、throw抛出

### 🔷 Stream流与文件
- [[Stream流]] - 函数式操作集合/数组、中间方法、终结方法、收集
- [[可变参数]] - 方法的语法糖、本质是数组、Stream流获取方式之一
- [[File类]] - 文件/文件夹对象、常用方法、遍历文件夹
- [[递归]] - 方法自调用、三要素、配合File遍历文件夹
- [[字符集]] - ASCII/GBK/UTF-8、编码与解码

### 🔷 IO流
- [[IO流]] - 输入/输出、分类、资源释放(try-with-resources/finally)
- [[字节流]] - FileInputStream/FileOutputStream、文件复制
- [[字符流]] - FileReader/FileWriter、刷新与关闭、文本读写

## 💡 学习原则
1. 设计从下往上画，编写从上往下写
2. 就近原则优先，可用this/super打破
3. 静态优先于对象存在
4. 统一标准避免屎山代码
5. String不可变，大量拼接用StringBuilder
