# MySQL 索引

MySQL 的索引，可以理解为**数据库的目录**，类似书本的目录 + 页码：通过目录、页码快速定位数据的位置。

索引也是基于内存的，所以特别快；而 MySQL 慢，是因为它是基于**硬盘**的。**索引页是存在内存里的**。

---

## ⚠️ 索引失效与全表扫描

索引失效的一个例子就是**索引顺序反了**。索引一旦失效，就会退化为**全表扫描**——从头开始一个个找。
