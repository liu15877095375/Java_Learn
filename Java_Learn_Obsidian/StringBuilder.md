# StringBuilder

字符串的工具类/容器，用于高效拼接字符串，解决String拼接产生过多对象的问题。

---

## 🎯 核心特点
1. StringBuilder是一个**容器**，并不是字符串本身
2. 拼接效率高：每次拼接把新内容加到容器里，在容器里完成拼接，不会浪费内存
3. 最终可以通过 `toString()` 转换为String对象

## 🔗 对比String
| 特性 | String | StringBuilder |
|------|--------|---------------|
| 可变性 | 不可变，每次拼接产生新对象 | 可变，容器内追加 |
| 内存效率 | 低（大量拼接浪费内存） | 高（容器内操作） |
| 使用场景 | 少量字符串操作 | 大量字符串拼接 |
