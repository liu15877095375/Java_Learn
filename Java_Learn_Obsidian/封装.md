# 封装

[[面向对象基础]]三大特性之首，核心是数据安全。

---

## 🎯 核心目的
成员变量要用[[private关键字]]去私有化，最终的效果是不能通过对象直接使用变量，需要通过get和set方法去使用变量。

> get和set方法要用public去公开，这样才能让对象去使用。

---

## 🔑 关键要点
- [[private关键字]]是实现封装的核心手段
- [[this关键字]]在get/set方法中区分成员变量和局部变量
- 使用 `alt + insert` 快捷键快速创建get/set方法

---

## 📚 三大特性关系
```
封装 → 继承 → 多态
```
封装是基础，[[继承]]扩展功能，[[多态]]实现多种形态。

---

## 🔗 关联知识点
- [[面向对象基础]] - 数据安全
- [[private关键字]] - 访问控制
- [[this关键字]] - 成员变量访问
- [[继承]] - 代码复用
- [[多态]] - 多种形态
