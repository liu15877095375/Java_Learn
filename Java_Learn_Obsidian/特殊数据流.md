# 特殊数据流

用来把数据和类型一起写出去的流。之前的流，把数据写到磁盘，数据会全部变成字符串，比如写整型 97 出去，到磁盘就变成了字符串 97。特殊数据流就是用来解决该问题的。

## 📌 构造器和常用方法

写出之后看起来会是乱码，但实际上不是乱码，因为其包含了数据类型。不是给人看的，是给机器用的。
