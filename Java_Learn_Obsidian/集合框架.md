# 集合框架

长度可变的容器，用于存储多个对象，区别于数组长度固定。

---

## 🎯 概述
集合是一种**长度可变**的容器，可以形象理解为链表。

与数组对比：
- 数组：长度固定，可以存储基本类型和引用类型
- 集合：长度可变，只能存储引用类型（基本类型会自动装箱）

---

## 🔗 与多态的关系
不使用泛型时，集合可以接受任意类型，但获取元素时只能用[[Object类]]去接，用[[多态]]的方式接收：
```java
ArrayList arrayList = new ArrayList(); // 可以存任意类型
```
> 这种方式不好，因为[[多态#弊端|多态有弊端]]，无法直接使用子类特有方法。
