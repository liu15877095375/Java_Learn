# 转换流

解决字符输入流汉字乱码问题的特殊流。当代码的编码方式（如UTF-8）和文件的编码方式（如GBK）不一样时，单纯的字符输入流会乱码，因为字符输入流默认用代码的编码方式去解码。

---

## 🎯 作用

获取文件的原始字节流，然后按照指定的字符编码转成字符输入流。这里的指定字符编码，是文件的字符编码。
