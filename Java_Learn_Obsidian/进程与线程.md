# 进程与线程

进程是正在运行的程序（软件），线程属于进程，一个进程可以有很多线程。进程中的多线程是并发和并行执行的。

![](images/2026-08-20-21-19-02-image.png)

---

## ⚡ 并发 vs 并行

### 并发

宏观上是同时执行多个线程，但在微观上是分开执行的，只是因为轮询很快才看上去像是同时执行。

### 并行

真正意义上的同时执行。**多核 CPU 才有并行。**

> Java 线程能不能并行，看操作系统是否把不同线程调度到**不同 CPU 核心**。就算代码开多线程，单核机器上只能是并发。
