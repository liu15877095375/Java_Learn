# 面向对象基础

面向对象编程是Java的核心思想，包含三大特性：[[封装]]、[[继承]]、[[多态]]。

---

## 🔐 数据安全问题
成员变量要用[[private关键字]]去私有化，最终的效果是不能通过对象直接使用变量，需要通过get和set方法去使用变量。

> 注意：get和set方法要用public去公开，这样才能让对象去使用。

---

## ⚡ 快捷键
使用 `alt + insert` 快捷键可以快速创建：
- [[构造方法]]
- get/set方法（配合[[this关键字]]使用）
