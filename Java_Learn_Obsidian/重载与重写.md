# 重载与重写

重载（Overload）与重写（Override）是 Java 面向对象的核心基础，也是面试高频题。二者名字相似，但本质完全不同：**重载是同一个类中方法的多态，重写是父子类间方法的覆盖**。

---

## 一、重载（Overload）

### 定义

在**同一个类**中，存在多个方法名相同，但**参数列表不同**的方法，这就是方法重载。

### 核心规则

判断重载只看一点：**方法名相同 + 参数列表不同**

- 参数列表不同：参数的类型、个数、顺序至少有一个不同
- 和返回值类型、访问修饰符、抛出的异常都没有关系
- 属于**编译期多态**：编译阶段就能确定调用哪个方法

### 代码示例

```java
public class Calculator {
    // 两个int相加
    public int add(int a, int b) {
        return a + b;
    }

    // 三个int相加（参数个数不同）
    public int add(int a, int b, int c) {
        return a + b + c;
    }

    // 两个double相加（参数类型不同）
    public double add(double a, double b) {
        return a + b;
    }
}
```

## 二、重写（Override）

### 定义

在**父子类继承关系**中，子类定义一个和父类**方法名、参数列表完全一致**的方法，覆盖父类的方法逻辑，这就是[[方法重写]]。

### 核心规则

口诀：**两同两小一大**

- 两同：方法名相同、参数列表相同
- 两小：子类返回值类型 ≤ 父类返回值类型（协变）；子类抛出的异常 ≤ 父类抛出的异常
- 一大：子类访问修饰符 ≥ 父类访问修饰符（不能更严格）
- 属于**运行期多态**：运行时根据对象的实际类型调用对应方法

### 代码示例

```java
// 父类
class Animal {
    public void eat() {
        System.out.println("动物吃东西");
    }
}

// 子类重写父类方法
class Dog extends Animal {
    @Override // 注解：校验是否符合重写规则，推荐加上
    public void eat() {
        System.out.println("狗吃骨头");
    }
}

public class Test {
    public static void main(String[] args) {
        Animal animal = new Dog(); // 父类引用指向子类对象
        animal.eat(); // 输出：狗吃骨头（运行时调用子类重写的方法）
    }
}
```

---

## 三、核心区别总结

| 维度     | 重载（Overload） | 重写（Override） |
| -------- | ---------------- | ---------------- |
| 作用范围 | 同一个类内部     | 父子类之间       |
| 方法名   | 必须相同         | 必须相同         |
| 参数列表 | 必须不同         | 必须相同         |
| 返回值类型 | 无要求         | 必须兼容（协变） |
| 多态类型 | 编译期多态       | 运行期多态       |

---

## 四、常见误区

- ❌ 误区：返回值不同就是重载
  ✅ 事实：重载只看参数列表，只有返回值不同的话，编译会直接报错。
- ❌ 误区：子类重写方法可以随便改访问权限
  ✅ 事实：只能扩大不能缩小，比如父类是 public，子类不能写成 private。
