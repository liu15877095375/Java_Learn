# Set集合

[[集合框架|Collection]] 的一个分支，具有与 [[ArrayList|List]] 不同的特点。

---

## 🎯 特点

| 特性 | Set | List |
|------|-----|------|
| 顺序 | 无序 | 有序（插入顺序） |
| 索引 | 无索引 | 有索引 |
| 重复 | 元素唯一（不重复） | 可重复 |
| 排序 | 默认从小到大排序 | 按插入顺序 |

> 这里的"无序"指的是不保证插入顺序，不是随机顺序。

## 📌 遍历方式

Set 无索引，所以不能用普通for循环遍历，但可以用：
- [[迭代器]] — 迭代器的优势场景
- 增强for循环
- [[Lambda表达式]]

---

## 📌 实现类

- [[HashSet]] — 基于哈希表，无序、无索引、不可重复
- [[LinkedHashSet]] — 基于哈希表+双链表，有序
- [[TreeSet]] — 基于红黑树，可排序

---

## 📊 单列集合使用场景

| 集合 | 适用场景 |
|------|---------|
| ArrayList | 需要索引、经常查询 |
| LinkedList | 频繁增删、首尾操作 |
| HashSet | 去重、不在乎顺序 |
| LinkedHashSet | 去重且保持顺序 |
| TreeSet | 需要排序 |
| Map | 键值对一一对应（如购物车） |
