# Set集合

[[集合框架|Collection]] 的一个分支，具有与 [[ArrayList|List]] 不同的特点。

---

## 🎯 特点

| 特性 | Set | List |
|------|-----|------|
| 顺序 | 无序 | 有序（插入顺序） |
| 索引 | 无索引 | 有索引 |
| 重复 | 元素唯一（不重复） | 可重复 |
| 排序 | 默认从小到大排序 | 按插入顺序 |

> 这里的"无序"指的是不保证插入顺序，不是随机顺序。排序指的是默认从小到大排序。

## 📌 遍历方式

Set 无索引，所以不能用普通for循环遍历，但可以用：
- [[迭代器]] — 迭代器的优势场景
- 增强for循环
- [[Lambda表达式]]
