# Object类

Java中的顶级父类，每一个类都直接或者间接继承该类。

---

## 🎯 地位
在Java中，有一个顶级父类Object，每一个类都直接或者间接继承该类。

- [[成员内部类|private内部类]]对外返回时，常用Object类型接收（[[多态]]）
- 所有类都可以重写Object中的方法，如toString()、equals()、hashCode()等

---

## 🔗 关联知识点
- [[继承]] - Object是所有类的根
- [[多态]] - Object可以接收任何对象
- [[方法重写]] - 重写Object方法
- [[成员内部类]] - Object接收私有内部类对象
