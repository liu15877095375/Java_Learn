# 类型转换

[[多态]]场景下，将父类引用转为子类类型，以调用子类特有方法。

---

## 🎯 背景
[[多态]]的弊端：无法调用子类的特有方法，因为编译看左边。

## 📌 解决方法：强制类型转换
通过强制类型转换可以弥补这个弊端。

> ⚠️ 注意：只能强转为**自己的真实类型**，否则会报ClassCastException。

## 🔒 安全转换
在强转之前，使用[[instanceof关键字]]判断类型。
