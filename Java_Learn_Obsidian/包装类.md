# 包装类

将基本数据类型包装成对象类型，使 [[泛型]] 也能接收基本数据。泛型擦除后类型恢复为 Object，而 Object 无法指向基本数据，所以需要包装类。

---

## 🎯 为什么需要包装类

[[泛型]]不支持基本数据类型，只能支持对象类型（引用数据类型）。如果非得让泛型接基本数据类型，就要把基本数据类型包装成对象类型。
